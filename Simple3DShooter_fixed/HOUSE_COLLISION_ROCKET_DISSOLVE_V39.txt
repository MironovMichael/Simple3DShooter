V39 FIXES

- House collision rebuilt from the supplied OBJ dimensions (12.15 x 6.86 x 15.0 at render scale).
- Houses are solid: the player cannot enter through doors/windows.
- Collision uses the same yaw as the visible house model.
- Separate roof collision volume blocks jumping/flying through the roof and can be landed on from above when descending.
- Visual OBJ is not reused as a physics volume, avoiding the old offset collision bug.
- Player rockets spawn 1.35 units ahead and have a 0.14 second launch grace period. During this grace period they do not collide with terrain, buildings, tunnels or submarines, preventing instant detonation when firing while using the jetpack.
- Every enemy kill now displays a short kill message for about 2.4 seconds.
- Defeated enemies emit a voxel/pixel dissolve animation for about 0.75 seconds before disappearing completely.
- Existing BeepBox-Song.wav looping music remains enabled through winmm/PlaySound.

Build note: this environment does not contain the Windows OpenGL/MSYS2 toolchain, so a native Windows compile cannot be performed here.
