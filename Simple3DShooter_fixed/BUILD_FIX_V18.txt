V18 BUILD FIX

Fixed linker error:
multiple definition of `Enemy::Enemy()`

Cause:
main.cpp contains its own Enemy struct used by the game, while Enemy.cpp defines a separate Enemy class with the same C++ type name. Both translation units therefore produced the same Enemy::Enemy() symbol, causing an ODR/linker collision.

Fix:
Enemy.cpp was removed from the executable source list in CMakeLists.txt. The main game implementation in main.cpp already owns the Enemy type and does not include Enemy.h, so compiling Enemy.cpp was unnecessary and caused the collision.

No gameplay code was removed. This only fixes the build/link stage.
