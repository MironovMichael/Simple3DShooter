V31 — РУССКИЙ ИНТЕРФЕЙС ШРИФТОМ IMPACT

Весь видимый игровой текст, меню, названия оружия, сообщения, цели миссий и HUD переведены на русский язык.

На Windows игра создаёт OpenGL-списки символов из системного шрифта Impact через GDI/WGL. Это позволяет использовать настоящий установленный Impact без добавления стороннего файла шрифта в архив.

Добавлена линковка gdi32 для Windows.

Если в системе отсутствует Impact, Windows использует системный механизм подстановки шрифта. Для точного совпадения с Impact установите шрифт Impact в Windows.
